# Profile Website 1

Elegant monochrome personal-profile frontend redesigned as a classic editorial portfolio.

## Architecture

```text
profile-website-1/
├── index.html
├── style.css
├── script.js
├── cover/       # original exported reference
└── profile/     # original exported reference
```

## Design
Black, charcoal, graphite, off-white and white only. Cormorant Garamond provides the classic luxury character while DM Sans handles utility text.

## UX
- Sticky navigation with mobile menu
- Scroll-reveal transitions
- Interactive project cards + detail modal
- Cursor light and card tilt on desktop
- Smooth back-to-top
- Contact feedback state
- Reduced-motion support
- Main frontend has no dependency on the missing legacy img folder
